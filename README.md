# Landing Page para Emprendedores

## Descripción

Este proyecto consiste en una landing page desarrollada para promocionar servicios y herramientas dirigidas a emprendedores. El objetivo es presentar la información de forma clara y atractiva, utilizando una interfaz moderna y fácil de navegar.

Fue desarrollado como parte de una práctica de Desarrollo Frontend en INTECAP, aplicando los conocimientos de HTML, CSS y JavaScript.

## Características

- Navegación entre secciones mediante enlaces internos.
- Diseño adaptable a diferentes tamaños de pantalla.
- Animaciones al hacer scroll utilizando IntersectionObserver.
- Código organizado en archivos separados para facilitar su mantenimiento.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en cualquier navegador web.
